 # 🍷 Wine Quality Prediction - Machine Learning

 ![Python](https://img.shields.io/badge/Python-3.8+-blue)
 ![Status](https://img.shields.io/badge/Status-Complete-green)
 ![License](https://img.shields.io/badge/License-MIT-yellow)

 ## Overview

 End-to-end machine learning classification model for predicting wine quality.
 The project demonstrates best practices in handling imbalanced multiclass data
 using LightGBM with SMOTE oversampling and rigorous cross-validation.

 ### 📊 Key Results
 - F1-macro Score: 0.365 (test), 0.374 (cross-validation)
 - Generalization Gap: 0.9% (excellent)
 - Best Model: LightGBM + SMOTE
 - Optimal Learning Rate: 0.05
 - Feature Count: 11 numerical

 ## Dataset

 UCI Wine Quality Dataset
 - Samples: 1,599
 - Features: 11 physicochemical properties
 - Target: Quality score (1-6, imbalanced)
 - Classes: 6 (class distribution: [48%, 30%, 14%, 5%, 2%, 1%])
